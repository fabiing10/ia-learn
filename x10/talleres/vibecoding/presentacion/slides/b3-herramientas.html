Misma spec, dos cajas

Criterio Caja cerrada Lovable Caja abierta Claude Code / Codex
Tiempo a primera versiónMinutos, sin instalar nadaMinutos de generación, más instalación y decisiones previas
Control sobre las piezasBajo: la herramienta decide base de datos, hosting y estructuraTotal: tú decides cada pieza
CostoCréditos por mensaje dentro de un plan mensualSuscripción o consumo por uso, más hosting y base de datos aparte
Un cambio que la caja no previóDepende de las integraciones que ofrezcaSe construye; el límite es tu spec
Cuando se rompeVolver a la versión anterior; poco diagnósticoEl error se ve y se corrige; exige leerlo
Salida del códigoGitHub en dos direccionesEs tuyo desde el primer archivo
Quién lo mantieneTú, dentro de la herramientaTú o un ingeniero, con el código en la mano
